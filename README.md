## Regole

1. **Completato** solo se confermato dal giocatore o provato in partita. **Da verificare** non significa completato.
2. Registrare ogni progresso nel file dedicato e nel diario.
3. Non confondere un programma consegnato con uno collaudato in gioco.
4. Conservare coordinate, schemi di impianti e programmi storici; non sostituirli senza conferma.
5. I conteggi Stark Estate sono riferiti alla **PREVIEW**, non all'isola intera.
6. Il repository è **pubblico** alla data di pubblicazione; evitare informazioni personali e credenziali.
